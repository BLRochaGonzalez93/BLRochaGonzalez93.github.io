Resumen técnico

Sokar funciona como proyecto de portfolio orientado a mostrar dirección visual, estructura de gameplay, interacción con el entorno y planificación de sistemas escalables para una experiencia de aventura.

Contenido preparado para sustituirse por capturas, código, vídeo, documentación y enlaces reales cuando el proyecto avance.

Flujo técnico previsto

En esta sección se recogen las próximas actualizaciones previstas para el proyecto en base a la especificación técnica.

  1. 01ExplorationMovimiento y lectura de zonas del escenario.
  2. 02InteractionInteracción con objetos, puntos de interés o eventos.
  3. 03ProgressionAvance del jugador por objetivos o escenas.
  4. 04PresentationUso de visuales, iluminación y UI para comunicar intención.
