Sobre mí

Soy Blas Luis Rocha González, desarrollador de videojuegos y game designer bajo el nick VRM Games. Mi foco principal está en Unity y C#, creando sistemas gameplay claros, prototipos jugables y documentación técnica útil.

Este portfolio muestra una evolución profesional real: proyectos seleccionados, repositorios ordenados, builds descargables, GDD/MDA y una presentación visual pensada para reclutadores.

Áreas de interés

  • Gameplay programming y arquitectura de sistemas
  • Controladores de jugador, cámara, input y UI
  • Prototipos jugables y documentación técnica
  • GitHub, Git LFS, releases y flujo profesional
