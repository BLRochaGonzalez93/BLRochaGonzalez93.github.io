Proyecto destacado U009 · Unity · C#

Kill Them All 2D

Prototipo roguelite top-down/isométrico inspirado en Vampire Survivors, centrado en supervivencia contra oleadas, progresión por gemas, habilidades mejorables y personajes diferenciados.

Qué demuestra

  • Auto-ataque, oleadas y spawn de enemigos.
  • Gemas, experiencia, subida de nivel y selección de mejoras.
  • Personajes, habilidades, HUD, sonido, música y VFX.

Ruta de revisión

  1. Leer la página del proyecto.
  2. Revisar GameManager, EnemySpawner, WaveData, PlayerStats, Weapon y UIUpgradeWindow.
  3. Descargar y probar la build publicada.

Sobre mí

Soy Blas Luis Rocha González, desarrollador de videojuegos bajo el nick VRM Games. Mi foco principal está en Unity y C#, creando sistemas gameplay claros, prototipos jugables y documentación que permita entender rápidamente el valor técnico de cada proyecto.

Este portfolio muestra una evolución profesional real: proyectos seleccionados, repositorios ordenados, README bilingües, GDD/MDA, builds descargables y una presentación visual pensada para reclutadores.

Áreas de interés

  • Gameplay programming y arquitectura de sistemas
  • Controladores de jugador, cámara, input y UI
  • Prototipos jugables, GDD/MDA y documentación técnica
  • GitHub, Git LFS, releases y flujo profesional de trabajo
